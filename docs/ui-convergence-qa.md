完整相簿開啟時按鈕預設為「自動播放」，沒有自行跳頁。以 DOM 事件啟動後，約一個五秒週期由 P01 前進至 P02，按鈕切換為「暫停」。在播放中觸發「下一頁」後，按鈕回到「自動播放」，表示手動翻頁已停止自動播放；頁面 mapping 與頁碼仍正確，當時相簿仍顯示共 14 頁。
